# 1.1.0-beta.2 — 社区续作候选

- 基础体验：16–28pt 待办字号、置顶开关、窗口位置与尺寸记忆、⌘N 聚焦新任务、⌘⇧H 切换历史。
- 归档：已完成任务跨日自动归档；支持手动归档、历史搜索、分类筛选和恢复。旧任务缺少完成时间时不猜日期，由用户手动归档。
- 分类：新增任务可填分类；每条任务的「···」可修改分类或设置提醒。
- 提醒：使用 macOS 本地通知，用户主动授权后安排；完成、归档、删除时取消待触发通知。最多安排最近 60 条未来提醒，超限会提示。过期时间不补发。
- 数据：独立使用 `~/Library/Application Support/JintianMeiBaihuoCommunity/todos-v2.json`；首次启动只读导入旧版数据，并保存原字节备份。原 App 与旧 JSON 不被修改。后续两个 App 不互相同步。
- 保护：损坏文件停止写入；保存失败不提交内存变更；删除需确认；空白编辑不再直接删除任务。

## beta.2 修复

- 构建后签署完整应用包，使本地通知使用正确的应用身份。
- 提醒时间对齐到所选分钟，避免隐藏秒数造成延迟。
- 使用独立窗口位置保存，关闭冲突的系统自动恢复；显示器不可用时限制到可见区域。
